## 복구

게임을 종료한 상태에서 설치 기록의 `replacedFiles`와 `removedFiles`를 확인한다.
백업의 `originals/` 아래에는 원래의 상대 경로로 파일을 보관했고,
`before-file-hashes.json`과 `before-mod-hashes.json`에 원래 해시를 기록했다.
새로 생긴 파일은 백업의 원본 목록과 대조하여 제거하고, `originals/`의 파일을
동일한 프로필 상대 경로에 복원한다. 서로 다른 버전의 호환 모드 JAR가 동시에
활성화되지 않도록 전체 모드 목록과 옵션의 리소스팩 선택도 함께 복구한다.
