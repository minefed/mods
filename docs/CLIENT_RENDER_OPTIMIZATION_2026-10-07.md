# 클라이언트 추가 최적화 — 2026-10-07

Minefed 전체 구성을 검토한 뒤 MTR, minefed-display, Chisels & Bits의 반복 작업을 줄였다.
Minecraft **1.20.4 / Fabric / Java 17**을 대상으로 빌드했다. 아래 수치는 제거한 연산을
검증한 결과이며, 실제 게임 FPS 향상률은 아니다. 게임 관찰 연결을 사용할 수 없어
이번 JAR로 플레이하거나 프레임 시간을 측정하지는 못했다.

## 변경과 검증된 효과

| 모드 | 변경 | 확인한 작업량 감소 | 유지한 동작 |
| --- | --- | --- | --- |
| MTR 4.0.5 | 기존 가림 판정 뒤에 차량 조명을 조회 | 가려진 비탑승 차량 1량의 렌더 호출당 월드 빛 조회 2회 → 0회 | 표시되는 차량은 매 호출 현재 조명을 조회. 탑승 예외, 차체·대차 변환, 공개 생성자 동작 유지 |
| minefed-display 1.0.2 | 화면 테두리 전체 경계가 시야 밖이면 베젤 정점 생성을 생략 | 32×32 화면의 시야 밖 베젤 정점 4,096개 → 0개 | 가장자리만 보이는 화면은 표시. 빈 URL 정리, 브라우저 생성·유휴 수명 처리 유지 |
| Chisels & Bits 1.5.10-FC | 캐시 적중 경로의 `containsKey`와 `get`을 단일 `get`으로 변경 | 실제 클래스 비교에서 캐시 적중 1,000회당 키 해싱 2,000회 → 1,000회 | 캐시 키·FIFO·supplier 처리 유지. 아이템 NBT 직렬화는 그대로 수행 |

MTR은 프레임 사이의 조명 캐시를 추가하지 않았다. C&B의 변경 범위는 공용 캐시 조회
한 메서드이며, 아이템 모델 전체를 새 캐시로 대체한 것이 아니다.

## 실행한 검사

- **MTR:** 일반 테스트 91개, 레일 8개, Mixin 8개, 빛 타입 호환 3개 통과.
  실제 차량 렌더 진입점에서 가림 전환, 조명 변경, 탑승 예외를 검사했다.
  일반·그림자 패스 플래그를 대입한 회귀 검사이며 실제 셰이더 실행 검사는 아니다.
  JDK 21로 빌드했으며 변경된 런타임 클래스는 Java 17 바이트코드다.
- **디스플레이:** 기존 정점·UV·레이어 순서 비교 13,552건(23,586,112정점), 새 시야 검사
  1,283건(6,920,640정점), 커서 회귀, OpenGL 깊이 가림, 알파 프레임버퍼 32쌍 비교 통과.
  네 방향과 시야 경계, 큰 NBT 크기, 월드 경계 좌표를 포함한다. 추가 셰이더 패스는
  미검증이며, CEF 종료는 실제 네이티브 종료 대신 종료 호출과 캐시 정리를 검사했다.
- **C&B:** `:core:test` 34개(신규 6개), `:fabric:remapJar` 통과.
  키 해싱 횟수, FIFO·clear, 해시 충돌, 중첩 NBT 변경, supplier·null·예외 계약을 확인했다.
- **상위 도구:** 빌드 도구 테스트 65개, 릴리즈 입력 테스트 17개 통과.
  최종 레시피 테스트 2개와 빌드 계획 검사도 통과했다.
- **산출물:** 외부·내장 JAR CRC, SHA-256, Fabric 메타데이터, 변경 클래스의 Java 17 바이트코드,
  리소스·기존 라이선스 고지 보존, 테스트 클래스 미포함을 확인했다. ZIP 안의 세 JAR도
  다시 해시를 대조했다. 전체 팩을 다시 빌드한 결과는 아니다.

상위에 기록된 모든 소스 gitlink와 lock의 일치를 확인했다. 이번 세 모드는 로컬 HEAD,
원격 통합 브랜치와 lock까지 일치한다. `python scripts/mods.py verify --sources`의
전체 로컬 체크아웃 검사는 기존 `Automobility-Refueled` HEAD와 lock의 차이로 중단됐다.
작업 전부터 존재하던 관련 없는 체크아웃 차이는 보존했다.

## 교체용 산출물

- 로컬 ZIP: `build/client-render-optimizations-20261007.zip`
- ZIP SHA-256: 같은 경로의 `.zip.sha256`
- [JAR별 SHA-256·크기·소스·호환성·검증 기록](../inventory/client-render-optimizations-2026-10-07.json)
- 압축 내부: `mods/`의 세 JAR, `PROVENANCE.json`, `notices/`, 설치 안내 `README.txt`

기존 Minefed 1.20.4 Fabric 구성에서 게임을 종료하고 세 모드의 기존 JAR를 백업한 뒤
교체하는 패치 묶음이다. 같은 모드의 구버전과 신버전을 함께 두지 않는다.
나머지 의존성은 기존 팩을 사용하며, 디스플레이 브라우저에는 기존 MCEF가 필요하다.
게임 설치 폴더와 옵션, 운영 서버 파일은 이번 작업에서 변경하지 않았다.

세 모드 본체의 소스·바이너리 라이선스는 MIT이며 원본 고지를 함께 보존했다.
이 표기는 내장 의존성 전체에 적용되지 않는다. 각 의존성은 자체 라이선스를 유지한다.
운영 기준본의 과거 JAR 해시는 바꾸지 않고 이번 빌드 해시를 별도 기록했다.

내장 의존성의 공식 라이선스·저작권 고지와 출처 증거를 ZIP의 `notices/dependencies/`에
보완했다. 예를 들어 LZ4는 Apache-2.0이다. Scena·Saecularia의 해당 릴리즈 태그 LICENSE와
내장 메타데이터는 MIT지만 POM은 GPL-3.0으로 달라, 양쪽 원문과 차이를 기록에 보존했다.
이 로컬 ZIP을 공개 배포용 라이선스 검토가 끝난 전체 팩으로 표시하지 않는다.
MTR에 포함된 라이브러리와 Noto 글꼴의 공식 고지도 보완했다. 버전 정보가 제거된
라이브러리는 관측한 패키지와 참고 고지의 버전을 구분해 기록했다.

C&B 비교 기준 JAR는 `12fd1d23b3e6fb929ccba01e034c46ae632acbe0`에서 만든 과거 산출물이다.
직전 소스 pin `353dbfbb1cbaddad499338f5c54a4b6b81f6529f`보다 오래되어, JAR 차이에는
이전에 반영된 네트워크 최적화 클래스도 포함된다. 이번 소스 변경은 캐시 조회와 해당
테스트에 한정된다.

## 후속 검증이 필요한 후보

WebStreamer 비동기 디코딩은 프레임 버퍼 소유권, 오디오 동기화, 세그먼트 전환과
종료 처리를 함께 검증해야 하므로 이번 변경에 포함하지 않았다. MTR 가림 판정의
작업 큐·비동기 결과 전달 재설계도 제외했다. 다음 성능 비교는 같은 팩·JVM·월드·시점에서
전후 평균 FPS와 프레임 시간 상위 백분위수를 측정해야 한다.
