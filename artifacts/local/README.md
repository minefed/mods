# 운영 소스 모드의 JAR 기준본

FileZilla에서 확인한 운영 JAR 중 소스를 서브모듈로 관리하는 모드의 기준본을 보관한다.
파일명, SHA-256, 출처, 소스 pin 및 라이선스는 `../../inventory/mods.lock.json`에 기록한다.
이 디렉터리의 JAR는 Git에 포함하지 않는다. 공식 다운로드가 있는 파일은 `scripts/mods.py hydrate`로 복원할 수 있다.
공식 파일과 일치하지 않는 minefed 자체 빌드 파일은 이 로컬 기준본을 보존하거나 운영 파일에서 가져와 해시를 검증한다.

서브모듈 커밋은 운영 JAR와 바이트 단위로 동일한 빌드를 보장하지 않는다. 최신 fork 및 지침 커밋과 운영 바이너리를 구분해 관리한다.
